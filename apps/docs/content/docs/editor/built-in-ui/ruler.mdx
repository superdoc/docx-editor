## Try the ruler

Expand the Editor and click in the document to activate its section. Drag either margin handle to reflow the page, then
switch between inches and centimeters without changing the margins.

<EditorDemo fixture='/fixtures/ruler-sample.docx' preset='ruler' title='Adjust page margins' />

The ruler follows the active section. In Viewing mode it remains visible but read-only. Web layout hides it.

`ui.ruler` controls the built-in surface. Show or hide it later with `toggleRuler()`.

`measurementUnit` is an Editor-wide preference, so it stays at the top level rather than inside `ui.ruler`. Set the
initial unit to inches or centimeters, then change it with `setMeasurementUnit()`.

## Pin the ruler

Provide a container to place the ruler outside the Editor mount. For example, put a sticky container inside the same
scroll area as the Editor:

```html
<div style="height: 80vh; overflow: auto">
  <div id="ruler" style="position: sticky; top: 0; z-index: 20; height: 0"></div>
  <div id="editor"></div>
</div>
```

```ts
const superdoc = new SuperDoc({
  selector: '#editor',
  document: '/sample.docx',
  ui: { ruler: { container: '#ruler' } },
});
```

The host controls the container's placement and scrolling. Print pages are centered in the available Editor space;
there is no separate page-centering setting. The ruler tracks the page position as the document scrolls, zooms, or
resizes, and its handles continue to edit the active section. When the visible page has a different width, the ruler
keeps the active section’s width and shares the visible page’s center rather than its edges. In affected older releases, returning to the top can
temporarily restore alignment, but it may be lost again when scrolling down.

`onPageMarginsChange` reports the changed side and the section's current margins in inches. Use the
[Document API sections reference](/document-api/reference/sections/) for other page setup changes.
