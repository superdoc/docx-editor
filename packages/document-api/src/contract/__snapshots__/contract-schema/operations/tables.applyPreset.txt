Word presets (IDs starting with \"word.\", such as \"word.grid-table-4-accent-1\") install the built-in Word table style definition into the document when needed and reference it from the table, so the result opens in Word as that named style and follows the document theme. Optional styleOptions set the header row, last row, first column, last column, banded rows, and banded columns flags; omitted flags keep the table's current settings. Word presets remove table-level borders and shading so the style governs them; direct cell or run formatting is preserved and can override the style. In real-time collaboration every client receives the style definition and the table change together. Word presets are direct edits only: tracked mode returns CAPABILITY_UNAVAILABLE. SuperDoc convenience presets \"grid\", \"minimal\", \"striped\", and \"accent\" keep their existing behavior: they write direct borders, banding, and header shading (accentColor overrides the \"accent\" color).
